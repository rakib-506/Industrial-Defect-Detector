# Install torch FIRST from the right index, then this file. The pins below match
# either build, because PEP 440 treats `==2.6.0` as satisfied by `2.6.0+cpu`, so
# pip will not replace what you already installed.
#
#   local machine with an NVIDIA GPU:
#     pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
#   CPU only, e.g. the Docker image for Hugging Face Spaces:
#     pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cpu
#
# then:
#   pip install -r requirements.txt
#
# Installing this file on its own pulls the default PyPI wheel, which on Linux
# drags in ~2.5 GB of CUDA libraries that a CPU deployment never uses.
#
# Verified on Python 3.12.3 / Windows 11 / GTX 1650 (4 GB).
